# Indie Film Collective 

The Indie Film Collective is a multi-page website dedicated to independent filmmaking. The website includes information about film screening, workshops, and creative collaborations. 

The website uses HTML and CSS with a responsive layout for mobile and desktop screens. No Javascript is used.

Portions of the written content for this website were generated with the assistance of ChatGPT and were reviewed and edited by the student. All HTML, CSS, and JavaScript were written by the student.
